# ملفات المصدر

- `build.py`: بيولّد ملفات اللوغو النهائية (SVG) بـ`brand/final/`
- `render.py`: بيحوّل ملفات SVG لـPNG بمتصفح Chromium
- `xl.py`: بيولّد ملف الإدارة `tools/naqra-management.xlsx`
- `competitors.html`: مصدر ملف تحليل المنافسين (بيتحوّل لـPDF بـChromium)
- `fonts/`: خطوط Sora وIBM Plex Sans Arabic (رخصة SIL Open Font License من Google Fonts)

المسارات جوّا السكربتات مكتوبة لجلسة العمل الأصلية، فعدّلها قبل ما تشغلها.
