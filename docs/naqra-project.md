# naqra | نقرة — ملف المشروع

مشروع لبيع ستاندات وبطاقات تقييم Google بتقنية NFC وأدوات NFC ثانية بالأردن. شخص واحد بيدير المشروع، والبضاعة من علي بابا.

آخر تحديث: أيلول 2026

## القرارات المعتمدة

| البند | القرار |
|---|---|
| الاسم | **naqra** بالإنجليزي، **نقرة** بالعربي |
| الدومين | **NaqraJo.com**، واحتياطي `getnaqra.com`، ولاحقاً `naqra.jo` بعد التسجيل التجاري |
| اليوزرنيم | **@naqra.jo** على انستغرام وفيسبوك وتيك توك |
| الإيميل (لاحقاً) | `hello@naqrajo.com` |
| السلوغن | قرّب تلفونك… وخلصت · One Tap. Done. |
| الشخصية | تقني ونظيف |
| الزبون الأول | مطاعم وكافيهات، صالونات وعيادات |
| اللغة | مزيج عربي أردني وإنجليزي |
| اللوغو | فكرة **C2**: حرف N بمربع أزرق بيطلع إشارة NFC، وتحته naqra ونقرة |
| أول منتج | ستاند تقييم Google من PVC بقاعدة مغناطيسية وشريحة NTAG213 |
| التخصيص | حالياً ستاندات جاهزة، ولاحقاً طباعة لوغو الزبون كخدمة Premium |
| أداة الإدارة | Google Sheets (نسخة الأوفيس على الجهاز مش مفعّلة) |

## أرقام تقديرية (غيّرها لما تعرف الحقيقية)

- سعر الستاند من المورد: 0.50–0.79 دولار، وأقل كمية 100 قطعة (من منتجات مشابهة على علي بابا)
- التكلفة واصل: حوالي **1.38 دينار** للستاند
- أسعار البيع المقترحة: ستاند 10 د.أ · ستاندين 17 · ثلاثة 23 · خمسة 35
- الربح الصافي التقريبي بعد الإعلان والتوصيل: 4.6 د.أ للستاند و10.2 للباقة الثنائية
